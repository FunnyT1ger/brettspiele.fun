Regeln

  • Ein Team zeichnet, die anderen raten.
  • Der Zeichner bekommt drei Begriffe und wählt geheim einen davon aus.
  • Richtig geraten: +2 Punkte. Überspringen: nächstes Team.
  • Keine Buchstaben, keine Zahlen, keine wilden PowerPoint-Pfeile. Außer ihr seid Monster.
  • Leertaste startet/pausiert, N neue Runde, Z Undo.

Export / Import

Speichere Teams, Punkte und eigene Begriffe als JSON. Praktisch, wenn das Spiel auf einem Beamer läuft.
